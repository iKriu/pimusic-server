# PiMusic Mini App — дизайн-контракт (Material 3 Expressive)

Основа — **Material Design 3 Expressive** и гайдлайны Google (m3.material.io): токены цвета/формы/типографики/
движения, компоненты M3, window size classes, доступность (WCAG AA, тач-цели 48dp). Платформа — Telegram
Mini App: учитываем тему Telegram, safe areas, BackButton/MainButton/SettingsButton, haptics.

## 1. Суть
- **Продукт:** «пульт» личного стриминга (Jellyfin + загрузчик): найти → скачать в медиатеку → слушать/следить.
- **Пользователь:** владелец и друзья, частые короткие сессии, телефон одной рукой.
- **Главное действие:** нажать «Скачать» и сразу увидеть состояние (в очереди → качается → в медиатеке).
- **Тон M3 Expressive:** эмоциональный, но функциональный — крупные выразительные заголовки, смелые формы,
  обложки как главный материал, цвет из музыки.
- **Запоминающаяся деталь:** *динамический цвет из обложки* — на страницах альбома/исполнителя схема M3
  (primary/secondary/tertiary/surface-контейнеры) генерируется из доминирующего цвета обложки (алгоритм HCT
  из Material Color Utilities — встроить упрощённую реализацию на JS без зависимостей), обложка «морфится»
  из круга в скруглённый квадрат при прокрутке шапки.

## 2. Токены
- **Цвет:** полная M3-схема ролей (`--md-sys-color-primary`, `on-primary`, `primary-container`,
  `on-primary-container`, `secondary*`, `tertiary*`, `error*`, `surface`, `surface-dim/bright`,
  `surface-container-lowest…highest`, `on-surface`, `on-surface-variant`, `outline`, `outline-variant`,
  `inverse-*`, `scrim`). Базовая схема — из seed-цвета **#F5A524** (янтарь, «ламповый звук»), тёмная и светлая;
  выбор темы — по `Telegram.WebApp.colorScheme`. Контент-схема — из обложки (страницы альбома/исполнителя,
  мини-плеер). Семантика: «в медиатеке» — tertiary (зелёно-бирюзовый тон схемы), ошибка — error.
- **Форма (M3E shape scale):** none 0, extra-small 4, small 8, medium 12, large 16, large-increased 20,
  extra-large 28, extra-large-increased 32, extra-extra-large 48, full. Морфинг форм на нажатие кнопок
  (скругление ↔ меньше), выразительные формы для акцентов (cookie/scallop «9-sided cookie» для кнопки
  «Волна», «pill», «soft burst» для бейджа) — через SVG clip-path / mask.
- **Типографика:** **Roboto Flex** (Google Fonts, вариативные оси wght/wdth/opsz/GRAD) + **Roboto** fallback,
  шкала M3: display L/M/S, headline L/M/S, title L/M/S, body L/M/S, label L/M/S и **emphasized**-варианты
  (более жирные) для заголовков и активных состояний; `tabular-nums` для длительностей.
- **Иконки:** **Material Symbols Rounded** (Google Fonts, переменный шрифт: FILL 0→1 для активной вкладки,
  wght 400/600, GRAD, opsz 24).
- **Высота (elevation):** уровни 0–5 через тональные surface-container, тени только у FAB/меню/диалогов.
- **Движение (M3E motion physics):** пружины — spatial fast/default/slow и effects fast/default/slow
  (`cubic-bezier`-аппроксимации + `linear()` для пружин), переходы контейнера (container transform) из
  карточки альбома в страницу альбома, shared axis для вкладок. `prefers-reduced-motion` → без анимации.

## 3. Window size classes и раскладки
| Класс | Ширина | Навигация | Раскладка |
|---|---|---|---|
| Compact | < 600 | **Navigation bar** снизу (4 пункта, активный — pill-индикатор) | одна панель; детали — полноэкранные страницы со стеком (BackButton) |
| Compact landscape | высота < 480 | **Navigation rail** слева (без подписей) | одна панель, шапки «collapsed»; сетки 4–6 в ряд |
| Medium | 600–839 | Navigation rail с подписями | одна панель; детали — страница; сетки 3–4 |
| Expanded | 840–1199 | Navigation rail | **две панели**: список (360dp) + детали (гибко), list-detail canonical layout |
| Large | 1200–1599 | Navigation rail (expanded/drawer-like) | две панели, детали шире; supporting pane для очереди загрузок |
| Extra-large | ≥ 1600 | Rail | три панели: список · детали · загрузки; контент ограничен по ширине |
- Определение класса по ширине **viewport Telegram** (`Telegram.WebApp.viewportStableHeight`, `resize`) и
  `@container`; учёт `env(safe-area-inset-*)`, `--tg-safe-area-inset-*`, `--tg-content-safe-area-inset-*`
  (fullscreen-режим Telegram), отступы 16dp compact / 24dp medium+.
- Тач-цели ≥ 48dp, фокус-кольцо M3 (3dp, `secondary`), клавиатура: `/` поиск, Esc назад, стрелки в сетках.

## 4. Компоненты M3 (используем)
Search bar → Search view; Segmented buttons («Треки | Альбомы | Исполнители»); Chips (история, фильтры);
Lists (one/two-line, с leading-обложкой и trailing-кнопкой состояния); Cards (filled/elevated) для альбомов;
**Carousel** (multi-browse) для дискографии на compact; Top app bar (**large flexible** на страницах
альбома/исполнителя, collapsing); **Button groups** и **Split button** («Скачать альбом ▾ — всё / недостающее»);
**Extended FAB** («Скачать всё» на артисте, прячется при прокрутке); Icon buttons (filled/tonal/outlined);
**Loading indicator** M3E (морфинг форм) для загрузки экранов; **Wavy linear/circular progress** для импорта и
трека «качается»; Snackbar (тосты с «Отменить»); Dialogs (подтверждения); Badges (число загрузок на вкладке);
Navigation bar / rail; Toolbar (floating) для фильтров медиатеки; Bottom sheet (действия трека).

## 5. Экраны и логика
1. **Поиск** — Search bar сверху (compact) / в панели (expanded); при фокусе — Search view с историей
   (chips, localStorage, 8 последних) и «Популярное у вас» (исполнители из медиатеки). Результаты: hero-карточка
   исполнителя (если совпадение) → segmented buttons со счётчиками → списки/сетки. Ряд трека: обложка 56dp
   (shape medium), title M, supporting text «исполнитель · альбом · 3:42», trailing — кнопка состояния:
   `download` (outlined) → wavy circular progress → `check_circle` (tertiary, FILL 1) «в медиатеке».
2. **Альбом** — Large flexible top app bar в контент-цвете обложки: обложка 240dp (морф при скролле),
   заголовок headline-emphasized, исполнитель (кнопка-ссылка), «2016 · 12 треков · 44 мин»; split button
   «Скачать альбом / Только недостающие»; треклист с номерами.
3. **Исполнитель** — круглое фото (shape full → morph), «N слушателей», button group «Популярное | Дискография
   | Все треки», carousel дискографии, extended FAB «Скачать всё» с диалогом подтверждения.
4. **Медиатека** — floating toolbar «Треки · Исполнители · Альбомы» + фильтр; сетка карточек (альбомы —
   квадрат, исполнители — круг), страницы своих альбомов/исполнителей, удаление через bottom sheet → диалог,
   snackbar «Удалено · Отменить» (если поддерживается — иначе без отмены).
5. **Загрузки** — карточка импорта: wavy linear progress, «осталось ≈ 2 ч 10 мин · 3,1 трека/мин», button group
   «Пауза | Стоп», «Что не нашлось»; «Сейчас качается» (list с wavy circular), лента событий; badge на вкладке.
6. **Волна** — hero-карточка extra-extra-large shape с коллажем обложек любимых альбомов (контент-цвет),
   cookie-кнопка «Слушать», tonal-кнопки «Обновить плейлист», «Найти новое» (с loading indicator и списком
   добавленного).
- **Глобально:** активные загрузки — badge на вкладке и мини-индикатор в top app bar; haptics (impact на
  нажатия, notification на успех/ошибку); Telegram MainButton на альбоме/исполнителе дублирует главное действие
  на compact; BackButton на стеке; SettingsButton → «О сервере».
- **Статус «в медиатеке»:** клиент кэширует ключи своей медиатеки (ISRC + «артист|название») из `/api/library`
  и показывает ✓; после «Скачать» — прогресс до события из `/api/activity`.

## 6a. Уточнения по итогам макета (design/canvas, «Тональный резонанс»)
1. **Роль «в медиатеке»** — отдельная success-роль: фиксированный зелёно-бирюзовый (hue 165), гармонизированный
   к seed не более чем на 15° (Material «harmonize»), а не tertiary контент-схемы (у синей обложки tertiary
   уходит в фиолетовый).
2. **Вместо segmented buttons — connected button group** (M3E): выбранный сегмент полностью скруглён, ширины
   гибкие по содержимому (равные трети не влезают в 328dp с «Исполнители 8»).
3. **Large (1200–1599):** collapsed rail 96dp с подписями (list 360 + detail ≥ 528 + supporting 360);
   expanded rail — только для XL или когда supporting pane скрыта.
4. **Navigation bar** — M3E flexible navigation bar 64dp + отступ home indicator.
5. **MainButton Telegram** на compact-альбоме не дублирует split button: показываем MainButton только когда
   split button ушёл за край при прокрутке.
6. **Fullscreen Telegram:** учитывать `--tg-content-safe-area-inset-top` (кнопки «Закрыть»/⋯ ≈ 46dp под статус-
   баром; на iPhone контент начинается ≈ 96dp).
7. **Радиусы 28/32/48** — только на объектах ≥ 112dp (обложка, карточки, панели); на 56–64dp они превращаются в круг.
8. **Трек прогресса** в тёмной теме — `surface-container-highest` вместо бледного `secondary-container`, чтобы
   загрузка читалась с первого взгляда.

## 7. Плеер очереди и плейлисты
**Направление.** Задача — слушать свою медиатеку одной рукой: найти список → тап по треку → играет; всё остальное
(очередь, плейлисты, друзья) — на расстоянии одного жеста. Тон тот же «Тональный резонанс»: обложка — главный
материал, схема «Сейчас играет» берётся из её цвета; форма и движение говорят о состоянии, а не украшают.
**Запоминающаяся деталь:** обложка «дышит» вместе с воспроизведением — на паузе скругление растёт 32 → 48dp и масштаб
0,9 (spatial-slow), при игре возвращается; кнопка ▶/❚❚ морфится «печенье ↔ круг» (выбор пользователя: пауза — cookie9, играет — ровный круг; так же «Слушать»
   Волны и мини-плеер), состояние передаёт подпись «Играть/Пауза» (без aria-pressed);
активная часть перемотки — волнистая (M3E wavy), на паузе и под reduced motion — прямая.
1. **Один `<audio>`, два режима.** `wave` (живой эфир, как раньше) и `queue` (файлы). Мини-плеер общий: волна —
   «В эфире» + ✕, очередь — исполнитель, прогресс-линия 3dp, ▶/❚❚ и ⏭. Тап: волна → экран Волны, очередь → «Сейчас играет».
2. **«Сейчас играет» по window size class:** compact — полноэкранный лист (свайп вниз за шапку, «Свернуть», BackButton,
   Esc); compact landscape — обложка слева, управление справа; medium/expanded — модальный side sheet 440dp справа со
   scrim; large/xl — закреплённая панель на месте supporting pane (загрузки уступают ей место, мини-плеер скрыт;
   открывается сама при старте очереди, пока пользователь её не закрыл). Порядок: обложка → название (headline-S
   emphasized) → исполнитель / альбом (text-кнопки-ссылки) → перемотка + время → shuffle · ⏮ · ▶ (80dp) · ⏭ · repeat →
   tonal «В плейлист» / «Очередь · N». Перемотка: role=slider, ←/→ ±5 с, PgUp/PgDn ±30 с, Home/End,
   aria-valuetext «1:23 из 4:46»; ручка 4×28dp с зазорами 6dp, точка-стоп в конце (M3E slider).
3. **Лист «Очередь»:** «Играет сейчас» (эквалайзер) + «Далее · N»: ручка (перетаскивание; ↑/↓ с клавиатуры, объявление
   «Позиция 3 из 12»), «Выше/Ниже» (видны при фокусе в ряду — альтернатива перетаскиванию для TalkBack/VoiceOver),
   тап — перейти, ✕ — убрать (объявляется, фокус остаётся в списке); вверху перемешивание и «Очистить» (с подтверждением).
   Compact — bottom sheet в контент-схеме плеера; side sheet и закреплённая панель — очередь открывается внутри самой
   панели («← Очередь», shared axis X). «Добавить в плейлист» на двух панелях — диалог по центру, на compact — bottom sheet.
   Shuffle — aria-pressed; repeat — состояние в подписи и объявление; включённое состояние — не только цвет:
   форма круг → скруглённый квадрат 12dp и обводка 2dp. Остаток дорожки перемотки — on-surface-variant 55% (≥ 3:1).
4. **Свои треки везде** (медиатека, альбом, исполнитель, плейлист): тап по ряду = играть список с этого трека
   (повторный тап по играющему — открыть «Сейчас играет»); шапки — filled «Слушать» + tonal «Перемешать».
   ⋮ / долгое нажатие / контекстное меню: bottom sheet на compact, меню M3 на двух панелях. Играющий ряд —
   primary-заголовок, эквалайзер поверх обложки (scrim 50%, белые столбики — читается на любой обложке) или вместо
   номера, `aria-current`; на паузе и под reduced motion столбики стоят.
5. **Плейлисты — четвёртый вид медиатеки, последним** («Треки · Исполнители · Альбомы · Плейлисты»): не ломает
   привычный порядок и позицию выбранного по умолчанию «Треки»; плейлисты — производное от медиатеки, а не отдельный
   раздел навигации (4 вкладки bar остаются). Глубокие ссылки `#playlists` / `#join=` сразу открывают этот вид.
   Когда панель списка уже 440dp (контейнер `pane`), floating toolbar — только иконки (заливка + подзаголовок
   «6 плейлистов» говорят, что выбрано); при прокрутке вниз toolbar прячется, при прокрутке вверх или фокусе — возвращается. Сетка: первая карточка «Новый плейлист» (пунктир outline-variant), карточки — мозаика 2×2 (1–3
   обложки — одна во весь квадрат, 0 — иконка на primary-container), «общий» — круглый tertiary-бейдж с group.
6. **Страница плейлиста** — тот же large flexible top app bar, что у альбома (без морфа в диск: квадрат 28 → 20dp),
   контент-цвет первой обложки; под названием — описание, чип «Общий» (tertiary-container), аватары-инициалы
   (4 тональных роли по хэшу логина) + «N участника» (открывает лист участников), «от bob · 12 треков · 42 мин».
   Режим правки (карандаш в баре → «Готово»): ручка + «Выше» / «Ниже» / «Убрать» у каждого ряда, перестановка на месте.
   Partial: треки не из медиатеки — курсивом «Не в медиатеке», плашка с подсказкой «Сохранить в медиатеку».
7. **Формы:** outlined text field (плавающая метка, счётчик 0/100), M3 switch (галочка в бегунке); диалог-форма
   держит «Создать» неактивной, пока имя пустое, Enter подтверждает.
8. **Состояния:** скелетоны сетки/списка; пусто — «Создайте первый плейлист» (cookie4), «В плейлисте пока пусто»
   (clover); ошибка — «Повторить»; 404 — «Плейлист недоступен» / «Приглашение недействительно» (softBurst, link_off);
   сервер без плейлистов — «Плейлисты пока недоступны»; трек не стартовал — одна попытка со свежей ссылкой, затем
   снекбар «Не удалось включить … — пропускаю».

## 9. Эквалайзер, фишки, вход
**Направление.** Эквалайзер — инструмент, а не игрушка: первым читается **кривая АЧХ** (герой экрана), всё
остальное — способы её поменять. Тон спокойный и точный (сетка 0/±6/±12 дБ, подписи частот), выразительность — в
форме и цвете: кривая и заливка в primary контент-схемы обложки, точки полос пронумерованы, выбранная — крупнее с
кольцом; позади — полупрозрачный спектр в tertiary (то, что звучит сейчас). **Запоминающаяся деталь:** точку можно
тянуть прямо по кривой (частота × усиление), колесо/щипок меняют ширину (Q), подсказка «2 кГц · +3 дБ · Q 1,40»
следует за пальцем; A/B («A · с EQ / B · оригинал») мгновенно гасит кривую до серой.
1. **Порядок экрана (сверху вниз):** режим «Синхронизировать | Только это устройство» (connected button group —
   решение пользователя: переключатель наверху) → «Эквалайзер» (switch) + A/B → кривая (180–280dp, extra-large
   радиус) → чипы полос 31…16k (radiogroup, стрелки) → карточка выбранной полосы: «Частота» (лог-шкала),
   «Усиление» (±12, шаг 0,1, ноль посередине), «Добротность (Q)» (0,3–8, лог); у крайних — «Пик | Полка» → «Преамп» →
   пресеты (filter chips, свои — со звёздочкой) + «Сохранить как…», «Переименовать», «Удалить», «Сбросить» →
   «Лимитер», «Спектр поверх кривой». На ≥ 760dp — две колонки: кривая слева, управление справа.
2. **Где открывается:** «Сейчас играет» → ряд инструментов (Текст · Эквалайзер · В плейлист · Очередь — tonal
   плитки 56dp, иконка над подписью) → вид внутри плеера («←» назад); «Настройки → Звук → Эквалайзер» — страница;
   «Настройки → Эквалайзер на других устройствах» — удалённая правка (плашка «Удалённая настройка: ТВ-приставка»,
   без звука и спектра здесь).
3. **Синхронизация:** ключи `eq.presets` (общая библиотека), `eq.shared` (общий активный профиль),
   `eq.device.<uuid>` (режим, имя, свой профиль, вкл/лимитер/спектр, `output: "default"` — задел под профили по
   выходу звука). Локально — сразу, на сервер — PUT по ключу с `base`, 409 → берём серверное.
4. **Слайдер M3E** (общий компонент): дорожка 16dp из сегментов (внешние углы full, внутренние 4dp), ручка 4×44dp,
   зазор 6dp между ручкой и сегментами, точка-стоп 4dp на конце неактивной дорожки (прячется, когда к ней подходит
   ручка); у дБ (ноль посередине) — активный сегмент от нуля до значения, неактивные слева и справа, стопы на обоих
   концах, отдельной метки нуля нет. Значение справа над дорожкой (primary, tabular) — или поле ручного ввода.
   Клавиатура: стрелки — мелкий шаг, Shift+стрелка и PgUp/PgDn — крупный, Home/End.
   **Ручной ввод (эквалайзер):** справа от подписи — плотное outlined text field 48dp (ширина clamp(104dp, 40 %,
   124dp), body-large tabular, выравнивание по правому краю, суффикс единиц «Гц»/«дБ» on-surface-variant,
   `inputmode=decimal`, подпись — label слайдера, `aria-describedby` — единицы и supporting text). Enter/blur —
   применить (живой предпросмотр + одна запись, как у отпускания ползунка), Esc — откат. Supporting text body-small
   под полем: значение вне границ зажимается и поясняется on-surface-variant («Допустимо от 20 до 20 000 Гц —
   установлено 20 000»); не число — состояние error (обводка и текст error, trailing-иконка error, `aria-invalid`).
   Принимаются запятая и точка, «−», пробелы; частота — «1500», «1.5k», «1,5 кГц».
   **Точность/шаги:** частота — 0,1 Гц до 100 Гц и 1 Гц выше (≤ 0,5 %), стрелка ×1,01, крупный шаг ⅓ октавы;
   усиление и преамп — 0,1 дБ, крупный шаг 1 дБ; Q — 0,01, стрелка ×1,02, крупный ×1,25. Формат: «+3,4 дБ»,
   «1 500 Гц», «31,5 Гц», «Q 1,40». Сохранённые значения с шагом 0,5 загружаются без изменений.
5. **Фишки плеера (меню ⋮ «Сейчас играет» и «Настройки»):** «Таймер сна» (лист: 15/30/45/60 мин, «До конца трека»;
   чип «Сон · 14:32» под шапкой плеера, затухание 8 с), «Скорость» (0,5–2×, чипы 0,75/1/1,25/1,5/2, высота голоса
   сохраняется; волна — всегда 1×), «Плавный переход» (0–12 с; 0 — без паузы, следующий заранее во втором
   `<audio>`), «Нормализация громкости» (по gain/peak сервера, подъём ≤ +6 дБ и не выше пика). Граф: `<audio>`×2 →
   gain дорожки → [преамп → 10 биквадов] → [лимитер] → master → анализатор; iOS — граф только с включённым вручную EQ.
6. **Текст песни:** крупные строки headline-S emphasized; прошедшие — 62 %, будущие — 42 % on-surface, текущая —
   primary + scale 1,03 (без масштаба под reduced motion); автопрокрутка к 38 % высоты, ручная прокрутка ставит её
   на паузу на 4 с; тап по строке — перемотка. Без меток — обычный текст; нет текста — пустое состояние clover.
7. **Вход вне Telegram (PWA/Windows/Android):** экран как gate — cookie9 с graphic_eq, «Вход в PiMusic», filled
   «Войти через Telegram» (ссылка t.me/<бот>?start=login_…, опрос каждые 2 с), статус (ожидание/ошибка/готово),
   «или отсканируйте с телефона» + QR (белая подложка, свой энкодер без зависимостей), виджет Telegram — только если

8. **PWA:** manifest (иконки 192/512/maskable — cookie9 янтарный с полосками эквалайзера на #17130e), ярлыки «Моя

9. **«Настройки»** (SettingsButton Telegram, аватар в поиске, логотип rail): Воспроизведение (нормализация, переход,

10. **Свои файлы** («Загрузки» сверху; «Медиатека» — кнопка рядом с «Слушать/Перемешать», перетаскивание на
   список): заголовок «Свои файлы» + filled «Загрузить файлы», зона перетаскивания (только для мыши), ряды с

   Сохранить»; карточка не перерисовывается, пока в ней фокус.
11. **Оформление** («Настройки → Оформление»): «Тема» — connected button group «Как в системе | Светлая | Тёмная»

## 8. Проверка
Viewports: `360x800`, `390x844`, `844x390`, `600x960`, `840x1200`, `1024x768`, `1280x800`, `1600x1000`;
светлая и тёмная схема; длинные названия (60+ символов, японский, кириллица); `prefers-reduced-motion`;
контраст AA для всех пар ролей; тач-цели ≥ 48dp; навигация с клавиатуры.
